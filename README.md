---

## 🚀 Características

- Interfaz en Java Swing con conexión a base de datos MySQL.  

---

## 🛠️ Tecnologías utilizadas

- **Java 17**  
- **Swing** (interfaz gráfica)  
- **MySQL** (base de datos)  
- **Maven** (gestión de dependencias)
